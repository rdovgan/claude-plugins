# domain-export

Phase 6. The only write outside the workspace this plugin makes. The guard allows creating a page only in the configured space under the configured parent, and updating only pages qa-docs created; Claude Code asks the user to approve each call.

## Steps

1. Read `qa-docs/domains/<slug>/meta.json`. Export only `verified` or `exported` documents; otherwise say what is missing and offer `/qa-docs:verify <slug>`. If a repository in `modules` has a newer commit now (session context lists changed domains), say so and recommend `/qa-docs:refresh <slug>` first; export only if the user insists.
2. The target comes from the session context (the export line) or `.qa-docs/config.env`: cloud, space, parent page. If it is not configured, stop and tell the user to ask the admin.
3. **Manual edits in Confluence.** If `confluence.pageId` is set, read the page (`getConfluencePage`, `contentFormat: markdown`) and compare it with `export/last-export.md`. If people changed it, show the differences and ask with `AskUserQuestion`: "Bring their edits into the document first" (Recommended: check each edit against the code, add what is right to `domain.md`, record what is wrong in "Differences") / "Overwrite their edits" / "Cancel".
4. Build the page body from `domain.md` in markdown:
   - first line, a note: "Generated by qa-docs from code at <repo@commit, ...>, verified by <who> on <date>. Changes go through qa-docs; manual edits are kept only if brought into the document." (in the document language);
   - mermaid blocks stay as code blocks with the language `mermaid`, each preceded by one line: "Diagram source (mermaid); open in mermaid.live to view it as a picture." (in the document language): Confluence here has no diagram renderer;
   - code references stay as inline code.
5. Publish with `contentFormat: "markdown"`: `updateConfluencePage` with the saved `pageId` and a `versionMessage` naming the commits, or `createConfluencePage` with the configured `spaceId` and `parentId` and the document title. Use the cloud id from the config (or `getAccessibleAtlassianResources`).
6. Save exactly the body you sent to `export/last-export.md`. Update `meta.json`: `status` = `exported`, `confluence.pageId`, `confluence.url`, `confluence.exportedAt`, `confluence.exportedModules` (copy of `modules`). Append a `history.md` entry with the link.
7. Finish with the page link in one line.

If the call is refused by the guard or the user, report it and stop; do not try another tool or another space.
